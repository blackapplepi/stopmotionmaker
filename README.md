# Stop-Motion Desk Pro v1.1

This version fixes the `SyntaxError: unterminated triple-quoted string literal`.

## Streamlit Cloud
Use `app.py` as the main file. Keep `editor.html` and `requirements.txt` in the same repository folder.

## Included
Photo import, camera capture, touch/mouse/trackpad dragging, scale/rotate controls, frame timeline, onion skin, 1:1/16:9/9:16 formats, local auto-save, JSON save/open, and WebM export.

## Not yet included
True two-finger pinch/rotate, MP4/GIF export, audio muxing, AI background removal, and cloud project storage.
